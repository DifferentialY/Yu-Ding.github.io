# Yu Ding — Academic Homepage

A responsive English academic homepage for GitHub Pages. No build process or dependencies are required.

## Publish on GitHub Pages

1. Use the target repository: https://github.com/DifferentialY/Yu-Ding.github.io
2. Upload the contents of this folder to the repository root, preserving the `assets` folder. Include `index.html`, `style.css`, and `.nojekyll`.
3. Open **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.
4. With the current repository name and no custom domain, the expected project homepage URL is `https://differentialy.github.io/Yu-Ding.github.io/`. The root personal homepage URL requires a repository named `DifferentialY.github.io`.

## Update content

Edit `index.html` for biography, publications, news, and dates. Replace `assets/portrait.jpg` to update the photograph. Edit `style.css` for appearance. All assets use relative paths to support both root and project repositories.

## Content notes

- Biography, education, email, publications, and portrait come from the owner's existing Google Sites homepage, including its English page: https://sites.google.com/view/ding-yu/english
- Google Scholar: https://scholar.google.com/citations?user=0JoiBaIAAAAJ&hl=en
- Visual direction follows https://wei-mao-2019.github.io/home/ : centered academic layout, white background, blue links, compact typography, biography with a portrait, and publication lists. No source code or personal content from that site was copied.
- Google Scholar returned an access limit during preparation; publications are based on the supplied homepage. No citation counts or unverified paper links were added.
- The 2026 domestic conference title is translated from Japanese. Its author romanizations are omitted because they were not verified.
- The existing page lists QCAV 2025 as both the 15th and 17th edition in different sections. The award entry uses “QCAV 2025” without an edition number.
- News entries summarize dates and the award already present on the existing homepage.

Prepared October 2026. GitHub publishing requires the owner's account or repository access.
